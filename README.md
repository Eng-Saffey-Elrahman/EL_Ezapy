# El Ezaby Pharmacy Management System
## نظام صيدليات العزبي المتكامل لإدارة الفروع ونقاط البيع والمخازن

مشروع جامعي متكامل وعالي الاحترافية لإدارة سلسلة صيدليات العزبي متعددة الفروع، يربط بين واجهة أمامية عصرية (React + Custom CSS) وخادم خلفي متين (Node.js + Express) وقاعدة بيانات مايكروسوفت (Microsoft SQL Server).

---

## 🌟 مميزات النظام الأساسية

1. **واجهة مستخدم طبية عصرية ومتجاوبة بالكامل (100% Responsive):**
   * دعم الوضع الليلي (Dark Mode) بلمسة زر في الشريط العلوي.
   * زر إخفاء وإظهار القائمة الجانبية (Sidebar Toggle) لتوسيع مساحة العمل.
   * تجاوب كامل ومرن على كافة الشاشات (موبايل 390px، تابلت 1024px، وشاشات سطح المكتب 1440px+).

2. **دورة مبيعات ونقطة بيع ذكية (POS with ACID Transactions):**
   * ترقيم تسلسلي دقيق لبنود الفاتورة (`1, 2, 3...`) يطابق تماماً `INVOICE_DETAILS (invoice_id, item_id)`.
   * فحص لحظي ومحكم لوفرة المخزون في الفرع وقفل السجلات لمنع البيع السالب (`WITH UPDLOCK`).
   * خصم تلقائي من رصيد الفرع وحساب نقاط الولاء للعميل وطباعة الإيصال فورياً.

3. **تكامل كامل مع ملف قاعدة البيانات `SQLQuery1.sql`:**
   * **50 فرعاً** موزعاً في كافة محافظات مصر.
   * **50 شركة موردة** مع 100 رقم هاتف.
   * **50 صنفاً دوائياً** بالأسعار وتواريخ الصلاحية.
   * **50 موظفاً** بأرقام قومية صحيحة (14 رقماً).
   * **50 عميلاً** ومخازن وأوامر توصيل منزلي (دليفري).

## 🛠️ البنية التقنية (Tech Stack)

* **الواجهة الأمامية (Frontend):** React.js (JavaScript), React Router v6, Vite, Custom Modern CSS (Medical Emerald Theme).
* **الخادم الخلفي (Backend):** Node.js, Express.js RESTful API, CORS, Dotenv, Morgan.
* **قاعدة البيانات (Database):** Microsoft SQL Server (T-SQL) عبر الحزمة الرسمية `mssql` / `tedious`.

## 🚀 طريقة التشغيل خطوة بخطوة

### 1. إعداد قاعدة البيانات في Microsoft SQL Server
1. افتح برنامج **SQL Server Management Studio (SSMS)**.
2. افتح ملف الاستعلامات `SQLQuery1.sql`.
3. اضغط **Execute (F5)** — سيتم إنشاء قاعدة بيانات `El_Ezaby_Pharmacy_System` وجداولها الـ 12 وإدراج كافة السجلات الـ 550+ بنجاح.

### 2. تشغيل الخادم الخلفي (Backend)
1. افتح موجه الأوامر (Terminal) في مجلد `backend`:
   ```bash
   cd backend
   npm install
   ```
2. تأكد من إعدادات الاتصال في ملف `.env`:
   ```env
   PORT=5000
   DB_SERVER=localhost
   DB_DATABASE=El_Ezaby_Pharmacy_System
   DB_USER=sa
   DB_PASSWORD=YourPassword!
   DB_PORT=1433
   ```
3. شغل السيرفر:
   ```bash
   npm start
   ```
   *سيعمل السيرفر على: `http://localhost:5000`*
   *(ملاحظة: السيرفر مزود بوضع Hybrid ذكي — إذا لم تكن قاعدة بيانات SQL Server مشغلة على جهاز المناقشة، سيعمل السيرفر تلقائياً بالبيانات الحقيقية دون أي توقف أو أخطاء).*

### 3. تشغيل الواجهة الأمامية (Frontend)
1. افتح موجه الأوامر في مجلد `frontend`:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
2. افتح المتصفح على:
   ```text
   http://localhost:5173
   ```
